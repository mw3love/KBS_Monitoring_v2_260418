============================================================
  KBS Monitoring v2 - 새 PC 설치 안내
============================================================

이 문서는 이 프로그램을 처음 설치하는 분을 위한 안내입니다.
순서대로 따라하시면 됩니다.  (예상 소요시간: 약 15~20분)


[준비물]
  - Windows 10 또는 Windows 11 PC
  - 인터넷 연결
  - 이 프로젝트 폴더


------------------------------------------------------------
 1. 프로젝트 폴더 준비
------------------------------------------------------------

  이 폴더 전체를 PC의 원하는 위치에 복사하세요.

------------------------------------------------------------
 2. Python 설치  (3.11 이상)
------------------------------------------------------------

  (1) 웹브라우저에서 아래 주소로 이동하세요.

        https://www.python.org/downloads/

  (2) 다운로드된 파일을 더블클릭해 설치를 시작합니다.

  (3) ★ 가장 중요 ★
      첫 화면 맨 아래의 체크박스를 반드시 체크하세요.

        [v] Add Python to PATH
        (또는  Add python.exe to PATH)

      이 체크를 빠뜨리면 다음 단계가 실패합니다.

  (4) "Install Now" 클릭 → 설치가 끝날 때까지 기다립니다.

  (5) 설치가 끝나면 창을 닫습니다. (PC 재시작 불필요)


------------------------------------------------------------
 3. 필요한 프로그램 자동 설치  (install.ps1 실행)
------------------------------------------------------------

  이 단계 하나로 아래 3가지가 모두 자동 설치됩니다.
    - Python 패키지(PySide6, OpenCV 등)
    - ffmpeg (자동 녹화 영상에 소리를 합쳐 저장하는 도구)
    - 설치 가능 여부 점검

  (1) 프로젝트 폴더를 엽니다.

  (2) 폴더 안의  install.ps1  파일을 마우스 오른쪽 버튼으로
      클릭합니다.

  (3) 메뉴에서  "PowerShell에서 실행"  을 클릭합니다.
      (메뉴에 없으면 아래 "쉬운 대체 방법" 참고)

  (4) 파란색 또는 검은색 창이 열리면서 자동 설치가 진행됩니다.

        [1/3] Python 확인 중...
        [2/3] Python 패키지 설치 중...   (5~10분 소요)
        [3/3] ffmpeg 설치 중...

  (5) 마지막에  "설치 완료!"  메시지가 보이면 엔터를 눌러 창을
      닫습니다.

  --- 쉬운 대체 방법 (오른쪽 클릭 메뉴에 PowerShell이 없을 때) ---

  (a) 윈도우 키를 누르고  powershell  이라고 입력합니다.

  (b) "Windows PowerShell" 을 마우스 오른쪽 클릭 →
      "관리자 권한으로 실행" 을 선택합니다.

  (c) 아래 명령을 입력하고 엔터. 중간에 [Y/N] 물으면 Y 입력.

        Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

  (d) 프로젝트 폴더로 이동합니다. 예시:

        cd "D:\KBS_Monitoring_v2"

  (e) 설치 스크립트를 실행합니다.

        .\install.ps1


------------------------------------------------------------
 4. 프로그램 실행
------------------------------------------------------------

  (1) 프로젝트 폴더를 엽니다.

  (2) 폴더 안에서  실행.bat  파일을 더블클릭합니다. (권장)
      ※ 이 .bat 은 어느 PC에서도 동작하도록 작성되어 있습니다.

      또는 main.py 를 더블클릭하거나, 폴더 주소창에 cmd 입력 후
      엔터 → 검은 창에서 아래 명령 입력:

        python main.py

  (3) 메인 창이 뜨면 설치 성공입니다.

  ※ 프로그램을 두 번 실행하면 "이미 실행 중입니다" 안내가 뜨면서
    두 번째 실행은 자동으로 종료됩니다. (의도된 보호 동작입니다.)


------------------------------------------------------------
 5. ffmpeg가 따로 필요할 때
------------------------------------------------------------

  보통은 3번 단계의  install.ps1  실행으로 ffmpeg까지 함께
  설치됩니다. 만약 3번에서 ffmpeg 부분만 "주의" 메시지가
  뜨면서 실패했다면, 폴더 안의 아래 파일을 더블클릭하세요.

      install_ffmpeg.bat

  창이 열리며 자동으로 ffmpeg 만 다시 설치합니다.

  ※ ffmpeg는 자동 녹화 영상에 소리를 합쳐주는 도구입니다.
    설치하지 않아도 프로그램은 정상 동작하지만, 녹화된 영상에
    소리가 빠집니다.


------------------------------------------------------------
 문제 해결 (자주 묻는 질문)
------------------------------------------------------------

  Q1.  "python을(를) 찾을 수 없습니다"  라고 나옵니다.
   →  2번 단계 (4)의  "Add Python to PATH" 체크를 빠뜨린 경우입니다.
       Python을 다시 설치하면서 반드시 체크하세요.

  Q2.  install.ps1 실행이 "이 시스템에서 스크립트를 실행할 수
       없습니다" 라고 막힙니다.
   →  위  "쉬운 대체 방법"  의 (b), (c) 단계를 먼저 한 뒤 다시
       시도하세요.

  Q3.  ffmpeg 설치가 자꾸 실패합니다.
   →  install_ffmpeg.bat 파일을 오른쪽 클릭 →
       "관리자 권한으로 실행" 으로 다시 시도해 보세요.

  Q4.  그 외 문제
   →  담당자 문의: minwoo@kbs.co.kr

  Q5.  인터넷이 없는 환경(폐쇄망)에서 텔레그램이 안 옵니다.
   →  정상입니다. 인터넷이 없으면 텔레그램 발송은 불가하지만,
       화면 깜빡임/소리 등 PC 자체의 알람은 그대로 동작합니다.

  Q6.  캡처보드 영상이 안 보입니다.
   →  설정 다이얼로그 → 영상설정 탭 → 포트 번호를 0, 1, 2, 3 으로
       바꿔가며 시도하세요. 캡처보드 모델에 따라 포트 번호가
       다릅니다. 올바른 포트를 고르면 메인 화면에 영상이 나옵니다.

  Q7.  필수 패키지가 없다는 오류 창이 뜹니다.
   →  3번 단계의 install.ps1 (또는 install.bat) 을 먼저 실행해
       Python 패키지를 설치하세요. 이미 실행했는데도 같은 오류가
       나면 install.ps1 의 [2/3] 단계에서 빨간색 오류 메시지가
       나왔는지 확인하세요.
