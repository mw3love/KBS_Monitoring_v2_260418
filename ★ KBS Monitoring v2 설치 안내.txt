============================================================
  KBS Monitoring v2 - 설치 및 실행 안내
============================================================

처음 설치하는 PC라면 1 → 2 → 3 순서로 진행하세요.
이미 설치된 PC는 3번(실행)만 하면 됩니다.

준비물: Windows 10/11 PC, 인터넷 연결, 이 프로젝트 폴더


------------------------------------------------------------
 1. 실행 환경 만들기 (python313_전환.bat) - 처음 한 번만
------------------------------------------------------------

  프로젝트 폴더의  python313_전환.bat  을 더블클릭하세요.

  - Python 3.13이 없으면 자동으로 설치하고, 이 프로그램 전용
    환경(.venv313 폴더)을 만든 뒤 필요한 부품을 설치합니다.
  - 5~10분 걸립니다. 마지막에 "전환 완료!"가 보이면 성공입니다.
  - 다른 프로그램이 쓰는 Python은 건드리지 않습니다.

  ★ 폴더를 새로 받았다면(다시 다운로드·복사) 이 단계를 꼭 다시
    하세요. .venv313 폴더는 다운로드에 따라오지 않습니다.
    빠뜨리면 프로그램이 다른 Python 버전으로 돌면서 며칠 뒤
    설정창·알림음이 먹통이 될 수 있습니다(실제로 있었던 사고).

  ※ Python 3.14 로는 실행하지 마세요(위 사고의 원인).


------------------------------------------------------------
 2. ffmpeg 설치 (install_ffmpeg.bat) - 처음 한 번만
------------------------------------------------------------

  install_ffmpeg.bat  을 더블클릭하세요.
  자동 녹화 영상에 소리를 넣는 도구입니다.
  설치하지 않아도 프로그램은 돌지만, 녹화 영상에 소리가 없습니다.


------------------------------------------------------------
 3. 프로그램 실행
------------------------------------------------------------

  프로젝트 폴더의  실행.bat  을 더블클릭하세요.
  메인 창이 뜨면 정상입니다.

  ※ 반드시 실행.bat 으로 실행하세요. (전용 환경 사용, 예약 재시작
    등 기능이 이 파일을 통해서만 정상 동작합니다.)
  ※ 두 번 실행하면 "이미 실행 중" 안내 후 두 번째는 자동 종료됩니다.

  [켜진 뒤 확인할 것]
  - 아래 시스템 로그에 "기동 점검: ✓ Python 3.13.x ..." 가 보이는지
    확인하세요. 3.13이 아니면 1번을 다시 하세요.


------------------------------------------------------------
 4. 처음 켰을 때 설정 복원 (새로 설치한 PC)
------------------------------------------------------------

  새로 설치하면 감지영역 0개, 텔레그램 꺼짐 상태로 뜹니다(정상).

  (1) 설정(톱니바퀴) → 저장/불러오기 탭 → 백업 설정 파일 불러오기
  (2) 알림설정 탭 → "시스템 이벤트 알림" 체크 확인
      ("연결 테스트" 성공만으로는 시스템 알림이 켜졌는지 모릅니다.
       두 가지를 따로 확인하세요.)
  (3) 프로그램을 껐다가 실행.bat 으로 다시 켜기
      (다시 켜야 기동 알림 같은 시스템 텔레그램이 나가기 시작합니다)


------------------------------------------------------------
 (선택) PC 켤 때 자동 시작
------------------------------------------------------------

  자동시작 등록.bat  더블클릭 → 다음 로그인부터 자동 실행.
  해제하려면  자동시작 해제.bat  더블클릭.
  (PC가 자동 로그인되도록 설정되어 있어야 효과가 있습니다.)


------------------------------------------------------------
 문제 해결
------------------------------------------------------------

  Q. python313_전환.bat 이 "Python 3.13 설치에 실패" 로 멈춤
   → https://www.python.org/downloads/ 에서 3.13 버전을 직접 설치
     (첫 화면 [v] Add Python to PATH 체크) 한 뒤 다시 실행.

  Q. 스크립트 실행이 "스크립트를 실행할 수 없습니다" 로 막힘
   → 윈도우 키 → powershell 입력 → "Windows PowerShell" 오른쪽 클릭
     → "관리자 권한으로 실행" → 아래를 입력한 뒤 다시 시도:
        Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

  Q. 캡처보드 영상이 안 보임
   → 설정 → 영상설정 탭 → 포트 번호를 0,1,2,3 으로 바꿔가며 시도.

  Q. 영상은 나오는데 소리(레벨미터·임베디드 오디오) 감시가 안 됨
   → 윈도우 설정 > 개인 정보 및 보안 > 마이크 → "마이크 액세스" 켜기.
     캡처보드 소리도 윈도우는 '마이크'로 취급합니다.
     (장치 재연결·재부팅보다 이것부터 확인하세요.)

  Q. 그 외 문제
   → 담당자 문의: minwoo@kbs.co.kr
