============================================================
  KBS Monitoring v2 - 설치 및 실행 안내
============================================================

처음 설치하는 PC도, 이미 설치된 PC도 실행.bat 하나만 더블클릭하면
됩니다. 빠진 부품은 실행.bat 이 알아서 설치한 뒤 프로그램을 켭니다.

준비물: Windows 10/11 PC, 인터넷 연결, 이 프로젝트 폴더

  ★ 폴더는 C:\KBS_Monitoring 처럼 짧은 경로에 두세요.
    폴더 경로가 길면(예: 바탕화면 안 깊은 폴더) 부품 설치가
    "Long Path" 오류로 실패할 수 있습니다.


------------------------------------------------------------
 1. 실행 (실행.bat)
------------------------------------------------------------

  프로젝트 폴더의  실행.bat  을 더블클릭하세요.

  - 처음 켤 때는 검은 창에 설치 과정이 나오며 5~10분 걸립니다.
    Python 3.13, 이 프로그램 전용 환경(.venv313 폴더), 필요한 부품,
    ffmpeg(녹화 영상에 소리를 넣는 도구)를 차례로 설치합니다.
    설치가 끝나면 메인 창이 저절로 뜹니다.
  - 설치 중에 윈도우의 관리자 승인 창이 뜨면 "예"를 누르세요.
  - 다음부터는 설치 없이 바로 켜집니다. 업데이트로 부품 목록이
    바뀌었을 때만 다시 설치합니다.
  - 다른 프로그램이 쓰는 Python은 건드리지 않습니다.

  ※ 반드시 실행.bat 으로 실행하세요. (전용 환경 사용, 자동 설치,
    예약 재시작 등 기능이 이 파일을 통해서만 정상 동작합니다.)
  ※ 두 번 실행하면 "이미 실행 중" 안내 후 두 번째는 자동 종료됩니다.

  [켜진 뒤 확인할 것]
  - 아래 시스템 로그에 "기동 점검: ✓ Python 3.13.x · ✓ 부품 ..." 이
    보이는지 확인하세요. "✗ 부품 누락"이나 3.13이 아닌 버전이 보이면
    인터넷 연결을 확인하고 프로그램을 껐다가 실행.bat 으로 다시 켜세요.


------------------------------------------------------------
 2. 처음 켰을 때 설정 복원 (새로 설치한 PC)
------------------------------------------------------------

  새로 설치하면 감지영역 0개, 텔레그램 꺼짐 상태로 뜹니다(정상).

  (1) 설정(톱니바퀴) → 저장/불러오기 탭 → 백업 설정 파일 불러오기
  (2) "지금 다시 켤까요?" 창에서 [지금 다시 켜기]
      (다시 켜야 기동 알림 같은 시스템 텔레그램이 나가기 시작합니다.
       [나중에]를 눌렀다면 나중에 직접 껐다가 실행.bat 으로 켜세요.)
  (3) 다시 켜진 뒤 알림설정 탭 → "시스템 이벤트 알림" 체크 확인
      ("연결 테스트" 성공만으로는 시스템 알림이 켜졌는지 모릅니다.
       두 가지를 따로 확인하세요.)


------------------------------------------------------------
 (선택) PC 켤 때 자동 시작
------------------------------------------------------------

  설정(톱니바퀴) → 알림설정 탭 → 자동 재시작 → "PC 로그인 때 자동 실행" 체크
  → 다음 로그인부터 자동 실행.
  끄려면 같은 곳에서 체크 해제. 프로그램이 아예 안 켜질 때는
  작업 관리자 → 시작 앱 → "KBS Monitoring v2"를 사용 안 함으로.
  (PC가 자동 로그인되도록 설정되어 있어야 효과가 있습니다.)

  프로그램이 갑자기 꺼지면(크래시) 실행.bat이 저절로 다시 켭니다(보통 1분 안).
  창의 X로 닫은 것은 다시 켜지 않습니다.


------------------------------------------------------------
 문제 해결
------------------------------------------------------------

  Q. 처음 켤 때 "Python 3.13 설치에 실패" 가 보이고 설치가 안 됨
   → https://www.python.org/downloads/ 에서 3.13 버전을 직접 설치
     (첫 화면 [v] Add Python to PATH 체크) 한 뒤 실행.bat 다시 실행.

  Q. 실행 환경을 처음부터 다시 만들고 싶음 (부품이 꼬였을 때)
   → 프로그램을 끄고  설치도구\python313_전환.bat  더블클릭(.venv313 을 지우고
     새로 만듭니다). 그다음 실행.bat 으로 켜기.

  Q. 녹화 영상에 소리가 없음 (기동 점검 "✗ ffmpeg 없음")
   → 설치도구\install_ffmpeg.bat 더블클릭으로 따로 설치할 수 있습니다.

  Q. 스크립트 실행이 "스크립트를 실행할 수 없습니다" 로 막힘
   → 윈도우 키 → powershell 입력 → "Windows PowerShell" 오른쪽 클릭
     → "관리자 권한으로 실행" → 아래를 입력한 뒤 다시 시도:
        Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

  Q. 캡처보드 영상이 안 보임
   → 설정 → 영상설정 탭 → 포트 번호를 0,1,2,3 으로 바꿔가며 시도.

  Q. 영상은 나오는데 소리(레벨미터·임베디드 오디오) 감시가 안 됨
   → 윈도우 설정 > 개인 정보 및 보안 > 마이크 → "마이크 액세스" 켜기.
     캡처보드 소리도 윈도우는 '마이크'로 취급합니다.
     (장치 재연결·재부팅보다 이것부터 확인하세요.)

  Q. 그 외 문제
   → 담당자 문의: minwoo@kbs.co.kr
