============================================================
  KBS Monitoring v2 - 설치 및 실행 안내
============================================================

처음 설치하는 PC라면 1 → 2 → 3 순서로 진행하세요.
이미 설치된 PC는 3번(실행)만 하면 됩니다.

준비물: Windows 10/11 PC, 인터넷 연결, 이 프로젝트 폴더


------------------------------------------------------------
 1. Python 설치 (3.11 이상) - 처음 한 번만
------------------------------------------------------------

  (1) https://www.python.org/downloads/ 접속 → 다운로드 → 실행
  (2) ★ 첫 화면 맨 아래 [v] Add Python to PATH 를 반드시 체크 ★
      (이 체크를 빠뜨리면 다음 단계가 실패합니다)
  (3) "Install Now" 클릭 → 완료까지 대기 → 창 닫기


------------------------------------------------------------
 2. 패키지 자동 설치 (install.ps1) - 처음 한 번만
------------------------------------------------------------

  Python 패키지 + ffmpeg(녹화 영상에 소리 합성)를 한 번에 설치합니다.

  - 프로젝트 폴더의  install.ps1  을 오른쪽 클릭
    →  "PowerShell에서 실행"  클릭
  - 자동 설치 진행 (5~10분). 마지막 "설치 완료!" 메시지 확인.

  [오른쪽 클릭 메뉴에 PowerShell이 없을 때]
    윈도우 키 → powershell 입력 → "Windows PowerShell" 오른쪽 클릭
    → "관리자 권한으로 실행" → 아래를 차례로 입력:
        Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
        cd "프로젝트폴더경로"   (예: cd "D:\KBS_Monitoring_v2")
        .\install.ps1


------------------------------------------------------------
 3. 프로그램 실행
------------------------------------------------------------

  프로젝트 폴더의  실행.bat  을 더블클릭하세요.
  메인 창이 뜨면 정상입니다.

  ※ 반드시 실행.bat 으로 실행하세요. (예약 재시작 등 기능이
    이 파일을 통해서만 정상 동작합니다.)
  ※ 두 번 실행하면 "이미 실행 중" 안내 후 두 번째는 자동 종료됩니다.


------------------------------------------------------------
 (선택) PC 켤 때 자동 시작
------------------------------------------------------------

  자동시작 등록.bat  더블클릭 → 다음 로그인부터 자동 실행.
  해제하려면  자동시작 해제.bat  더블클릭.
  (PC가 자동 로그인되도록 설정되어 있어야 효과가 있습니다.)


------------------------------------------------------------
 문제 해결
------------------------------------------------------------

  Q. "python을(를) 찾을 수 없습니다"
   → 1번의 "Add Python to PATH" 체크 누락. Python 재설치하며 체크.

  Q. install.ps1 이 "스크립트를 실행할 수 없습니다" 로 막힘
   → 2번의 [PowerShell이 없을 때] 절차(관리자 권한 + ExecutionPolicy)
     를 먼저 한 뒤 다시 시도.

  Q. 캡처보드 영상이 안 보임
   → 설정 → 영상설정 탭 → 포트 번호를 0,1,2,3 으로 바꿔가며 시도.

  Q. 그 외 문제
   → 담당자 문의: minwoo@kbs.co.kr
