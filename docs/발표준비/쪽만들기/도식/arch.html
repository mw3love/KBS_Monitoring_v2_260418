v1은 감시 반복이 조용히 멈춰도(freeze) 아무도 몰랐다. v2는 프로그램을 셋으로 나누고, Watchdog이 나머지 둘이 살아 있는지 확인한다.

감시가 멈추면 — v1의 freeze가 이 모양

메인 루프가 멈춤창은 멀쩡해 보여서 사람은 모른다
20초 넘게 서명 없음
기록 일꾼이 heartbeat 기록을 일부러 멈춤어디서 멈췄는지 스택 덤프도 남김
10초 동안 안 바뀜
Watchdog이 강제 종료 → 새로 띄움UI가 지금 상태(감시 ON/OFF · 음량 · 정파 · 감지영역)를 다시 알려 줌
텔레그램 「중단 감지」 → 「복구 완료」운영 90일 중 자동 재기동 3회, 모두 1초 안
UI 화면이 멈춤생존 시각이 30초 묵으면 「UI 응답 없음」 알림
UI가 꺼짐10초마다 확인 → Detection 정리 + 알림
계속 죽음다시 띄우는 간격 5→10→20초…(최대 5분), 알림은 요약
UI가 고장 나 알림을 못 보냄파일 하나만 쓰면 Watchdog이 대신 알림 (8장)
