질문 대비용 부록. - 영상 버퍼는 프레임 개수, 소리 버퍼는 샘플 수로 크기가 정해져 덮는 시간이 다름 → 늦은 쪽에 맞춰 앞을 자름. - 실제 담긴 속도가 설정보다 낮아 그대로 묶으면 영상이 빨리 재생됨(실측 6.5%). 실제 속도를 재서 ffmpeg -itsscale로 시간 눈금만 바꿈. - 측정: ffmpeg volumedetect.
