문제측정 · 결과
영상이 점점 빨라짐설정 fps보다 실효 fps가 낮아 약 6.5% 차이 (20 s당 1.3 s 어긋남) → 실효 fps로 되돌림. 계수 0.5~4.0 밖이면 보정 안 함
파일 앞부분 무음2026-09-22 수정 후 실제 경보 녹화본의 첫 1 s 평균 음량 −33 ~ −37 dB (무음이면 −90 dB 안팎)
ffmpeg 없음영상만 MP4로 폴백 (에러 아님)
질문 대비용 부록. - 영상 버퍼는 프레임 개수, 오디오 버퍼는 샘플 수로 크기가 정해져 덮는 시간이 다름 → 시작점을 늦은 쪽에 맞춤. - 영상 push 실효 fps가 출력 fps보다 낮아 그대로 묶으면 영상이 빨리 재생됨(실측 6.5%). 실효 fps를 재서 -itsscale로 타임스케일만 바꿈. - 측정: ffmpeg -t 1 -af volumedetect.
