[약 1분 10초] - 프레임 단위 판정은 경계에서 흔들린다. 그래서 '지속 시간'과 '복구 히스테리시스'로 상태를 만든다. 예시: 블랙이 5초 이어져야 경보, 중간에 정상 1프레임이 끼어도 유지, 정상이 2초 이어져야 복구. - 정파 FSM: KBS 정파 시작 시각은 실측 00:40~03:50으로 불규칙, 해제는 04:30 이후로 거의 고정(실측 2TV 04:45 / 1TV 04:50). - 예전엔 시간이 되면 강제로 정파 모드에 넣었는데, 실제 정파가 늦으면 그동안 정상 방송의 경보를 묵살했다(오진입). 오류 비대칭: 오진입은 실사고 묵살, 미진입은 헛알림 몇 개. 그래서 진입은 감지 단독, 해제는 시간 상한. - 진입 기준 120초: 60초일 때 5/18 새벽 정상 화면이 60초 스틸로 잡혀 01:02에 잘못 진입한 사례 → 120초로. - 아래 그림이 실제 기록: 00:30 준비[시간] → 01:06 정파[감지] → 04:45 해제[감지].
