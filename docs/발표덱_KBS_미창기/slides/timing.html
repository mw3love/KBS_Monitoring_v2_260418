정파로 잘못 들어가면 진짜 사고를 새벽 내내 놓친다. 늦게 들어가면 헛알림 몇 개. 그래서 들어갈 땐 화면을 보고, 나올 땐 시간 상한을 둔다.

[약 1분 10초] - 매 순간 판정은 경계에서 흔들린다. 그래서 「이어진 시간」으로 경보를 만든다. 블랙 5초면 경보, 정상 한 번 끼어도 유지, 정상 2초 연속이면 복구. 켜는 조건과 끄는 조건을 다르게 두는 것 = 히스테리시스(절체기 자동 복귀 지연과 같은 생각). - 정파: 시작 시각은 실측 00:40~03:50으로 들쭉날쭉, 해제는 04:45~04:50 거의 일정. - 예전엔 시각이 되면 강제로 정파 모드에 넣었는데, 정파가 늦은 날엔 정상 방송의 경보까지 꺼 버렸다(오진입). 오진입은 실사고를 놓치고, 미진입은 헛알림 몇 개 → 들어갈 땐 화면을 보고, 나올 땐 05:00 시간 상한. - 120초: 60초였을 때 5/18 새벽 정상 화면이 우연히 60초 멈춰 01:02에 잘못 들어갔다 → 120초로. - 질문 대비: 04:30 전에 정파 화면이 움직이면 바로 「준비」 상태로 돌아간다(06-08부터, 조기 복귀).
