[약 1분] - Detection 프로세스 안에 스레드 셋 + 메인 루프. - 캡처 스레드는 계속 최신 프레임을 공유메모리에 씀. 락 대신 seqlock: 쓰기 전 seq를 홀수로, 다 쓰면 짝수로. 읽는 쪽은 읽기 전후 seq가 같고 짝수면 온전한 프레임. 1프레임 지연은 허용. - 메인 루프는 200 ms 주기: 맨 앞에서 heartbeat를 찍고(멈추면 감시자가 앎), 프레임을 읽어 ROI별 판정 → 상태기계 → 이벤트 → 남은 시간만큼 sleep. 목표 주기와 실제 경과 차이(지터)를 누적해 로그로 남김. - 느린 일(HTTP 발송, MP4 인코딩)은 전부 별도 스레드/큐로 빼서 판정 주기를 막지 않음. - 오디오는 별도 스레드가 PCM을 받아 RMS를 계산, 레벨 값은 고빈도라 큐가 아니라 공유메모리(kbs_state_v2)로 UI에 넘김.
