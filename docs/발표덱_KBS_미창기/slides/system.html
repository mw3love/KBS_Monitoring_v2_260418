항목값

채널마다 디코더·디임베더를 두지 않고, 멀티뷰어 출력 한 장을 잘라 16채널을 동시에 본다.

[약 1분] - 신호 흐름: 방송 신호 → 멀티뷰어(16분할 + 레벨미터) → 캡처보드 → 감시PC → 화면/경보음, 텔레그램, MP4. - 핵심 발상: 채널별 장비를 늘리지 않고 멀티뷰어 출력 한 장을 입력으로 씀. 그 위에 사람이 사각형(ROI)을 그려 센서처럼 쓴다. - 왼쪽 그림: 빨간 사각형 V1 = 1TV ON-AIR 영상 ROI, 왼쪽 레벨미터 위 주황 사각형 A1 = 같은 채널 오디오 레벨미터 ROI. - 캡처는 DirectShow 백엔드, 버퍼 1장 → 늘 최신 프레임으로 판정(지연 누적 방지). - 오디오는 캡처보드 오디오 장치(윈도우에선 '마이크'로 취급)에서 PCM으로 받음.
