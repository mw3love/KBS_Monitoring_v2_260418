오디오 판정

소리를 「보는」 레벨미터와 「듣는」 임베디드

레벨미터 (A) — 멀티뷰어가 그린 미터를 영상으로 읽기

cvtColor(BGR → HSV)

inRange H 40–95 · S 80–255 · V 60–255
(미터의 초록 막대만 통과)

통과 픽셀 비율 → 최근 5프레임 이동평균

≥ 5% = 소리 있음 · 미만이 60 s → 경보

A1 실측 (왼쪽 그림)

통과 15.6% → 활성

운영 화면 캡처에 같은 연산을 적용해 다시 계산

임베디드 (EA) — 실제 PCM 측정

int16 PCM

sounddevice 입력 스트림, L/R 분리 후 ÷ 32768

RMS → dBFS

20·log10(RMS), −60 ~ 0 dB로 클립

(L + R) / 2 ≤ −50 dBFS

60 s 지속 → 경보 · 정상 신호 오면 즉시 복구

장치 열기가 실패하면 그 시간을 무음으로 계산하고, 60 s 이어지면 [SYSTEM] 통보 — 2026-10-27 윈도우 마이크 권한이 꺼져 8시간 소리 감시가 멈췄던 사고 이후

[약 1분] - 레벨미터 감지: 멀티뷰어가 화면에 그려 주는 레벨미터를 영상으로 읽는다. HSV로 바꾸고 초록 막대 색 범위만 통과시켜, 통과 픽셀이 5% 미만이면 무음으로 본다. 5프레임 이동평균으로 미터 깜빡임을 흡수. - 장점: 디임베더 없이 화면에 보이는 채널 수만큼 소리 유무를 확인. 한계: 미터 색·위치에 의존 → 멀티뷰어 설정이 바뀌면 HSV 범위·ROI 조정 필요. - 왼쪽 그림은 실제 운영 화면의 A1에 같은 연산을 한 결과. 15.6% 로 활성. - 임베디드: 캡처 입력 PCM을 직접 측정. RMS → dBFS, L/R 평균이 −50 dBFS 이하로 60초면 경보. - 10월 27일 윈도우 마이크 권한이 꺼져 장치를 못 열었는데, 그땐 '측정값 없음'이라 경보가 안 울렸다. 지금은 열기 실패 구간을 무음으로 쳐서 무음 경보가 울리고, 60초 지나면 시스템 알림도 보냄.
